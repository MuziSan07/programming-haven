# Programming Haven — Roadmap

## Phase 0 — Investor demo (now, $0 budget)

Runs on a single laptop with the Groq free tier; deployable with one `docker compose up`.

- Auth, dashboard, XP / streaks / Readiness Score
- Python Language Path + AI tutor
- DSA Track: editor, Python & JavaScript execution, hidden tests, AI hints and code review
- Proctored mock test (browser face detection, tab / paste / fullscreen monitoring)
- AI Mock Interview: technical, HR, English rounds; animated avatar; voice in/out; scored report
- Company Prep Paths

## Phase 1 — Public beta (0–3 months after funding)

- Cloud deployment (frontend on Vercel / backend + Postgres on a managed host)
- Production code sandbox (Judge0 / isolate cluster) with 10+ languages
- JavaScript, Java and TypeScript Language Paths; 150+ DSA problems
- Skill Tracks: Full Stack, Frontend, Backend with hands-on projects
- Take-Home Project module with AI rubric review
- Payments (Stripe / Lemon Squeezy), Free / Pro tiers
- Native-feeling mobile via PWA install

## Phase 2 — Growth (3–9 months)

- Photo-real video avatars for interviews (premium)
- Live 1:1 pair-programming simulation (AI interviewer watches your editor in real time)
- System-design whiteboard round
- AI-generated problem variants to prevent memorisation
- Server-side proctoring evidence (snapshots, keystroke dynamics, AI-code detection)
- Mobile apps (React Native) for lessons and interviews on the go
- Community: peer mock interviews, leaderboards, success stories

## Phase 3 — Platform (9–18 months)

- B2B: white-label proctored assessments for recruiters and talent networks
- "Verified by Programming Haven" profile that candidates share with employers
- Job board and referral partnerships with remote networks
- AI/ML, Data Science and Mobile Skill Tracks
